==============================================================================
INTRODUCTION                                                       *viper-ide*

This plugin is supposed to be the analogue for the official Viper IDE for VS
Code, just for Neovim instead. It provides an LSP configuration with a
verification command.

==============================================================================
USER COMMANDS                                             *viper-ide-commands*

:LspViperVerify                                              *:LspViperVerify*

Start the verification of the current buffer.

:LspViperStop                                                  *:LspViperStop*

Stop the verification of the current buffer.

LSP COMMAND PROTOCOL                                         *viper-ide-proto*

Note: This is an unofficial documentation of the non-standard LSP commands of
the ViperServer language server (in lua-y notation). The information contained
here is simply how I think the protocol works from reading the source code of
the server and is solely used to document what this implementation assumes the
protocol to be.

From what I've been able to piece together, the source of truth for these is
the file 'ViperProtocol.ts' in the code of the official Viper IDE repository,
from which most of the information in this section is sourced.

CLIENT-TO-SERVER-COMMANDS                                *viper-ide-proto-c2s*

GetVersion (Request) ~

Request by the client to perform a compatibility check.

Request: >lua
    {
        -- Version of the client.
        ---@type string
        clientVersion = ""
    }
<
Response: >lua
    {
        -- Version of the server.
        ---@type string
        serverVersion = ""
        -- Error message if client is not supported by server, nil otherwise.
        ---@type string?
        error = ""
    }
<
Verify (Notification) ~

Notification by the client to start verification for a file.

Notification: >lua
    {
        -- File to verify.
        ---@type string
        uri = "",
        -- Contents of the file to verify.
        ---@type string
        content = "",
        -- Was the verification triggered manually?
        ---@type boolean
        manuallyTriggered = false,
        -- The path to the open workspace folder.
        ---@type string
        workspace = "",
        -- The backend to use. Either "silicon" or "carbon".
        ---@type string
        backend = "",
        -- Contains the path of the fild that should be verified.
        -- (TODO what??)
        ---@type string
        customArgs = ""
    }
<
StopVerification (Request) ~

Request: >lua

        -- The URI of the file to stop verifying.
        ---@type string
        uri = "string"
    }

Response: >lua
    {
        -- Whether or not the stopping worked.
        ---@type boolean
        success = false
